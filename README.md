# Minimalist Terminal Portfolio

A high-performance, minimalist portfolio designed with a Linux terminal aesthetic.

## Features
- **Terminal UI**: Content is wrapped in a terminal-style window with a custom title bar and buttons.
- **Vibe**: Dark mode, monospace typography, and command-line prompts.
- **Performance**: Zero frameworks, pure HTML/CSS.
- **Responsive**: Adapts from desktop centered window to mobile full-screen.

## Tech Stack
- HTML5
- Vanilla CSS
- Minimal JavaScript (for dynamic uptime/date)

## Colors
- **Background**: `#050505` (Deep Black)
- **Text**: `#d1d5db` (Gray-300)
- **Accent**: `#10b981` (Emerald-500)
- **Muted**: `#374151` (Gray-700)
